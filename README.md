### Airbnb Basque Country Price Prediction

The goal of this project is to analyze the prices of Airbnb listings in Basque Country using machine learning, where I'm currently based. Basque Country, with its coastal and mountainous areas, is an attractive region for both nature and cultural tourism, so analyzing Airbnb data from the area is worthwhile. I obtained the dataset from [this link](https://insideairbnb.com/get-the-data/).

Since the problem is about the prediction using labeled data, it requires a supervised machine learning method. And, since the prediction is about continuous numerical values, the problem is called regression problem. In this project, I used three different models to test my assumptions about the dataset, and then chosed the best one based on their train CV scores. One of those models is Ridge Regression, which is basically a linear model that can deal with multicollinearity problem. As the dataset at hand contains features that are linearly dependent or highly correlated with each other, such as accommodates, bedrooms, beds, bathrooms etc., Ridge Regression comes in handy for the multicollinearity problem caused by that high correlation. The other two models are Random Forest and Gradient Boosting, which are ensemble tree learning algorithms and can capture the nonlinear relationships between features and the target variable.
